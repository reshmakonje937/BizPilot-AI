BizPilot AI - Login Page Add-on

This ZIP keeps the original BizPilot AI dashboard and adds a demo login page.

How to run:
1. Extract the ZIP.
2. Open the BizPilot_AI folder.
3. Open login.html in your browser (or use VS Code Live Server).
4. Enter any valid email address and a password of at least 6 characters.
5. The existing dashboard opens. Use Sign out to return to the login page.

Important: This is a front-end demonstration login only. It does not verify real accounts and is not secure authentication. For real accounts, integrate Firebase Authentication. Existing dashboard data and features remain browser-local as in the original ZIP.
